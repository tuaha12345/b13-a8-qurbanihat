# QurbaniHat – Livestock Booking Platform

**QurbaniHat** is a modern livestock marketplace designed for users to explore and book animals for Qurbani, such as cows and goats. The platform provides a seamless experience for browsing featured animals, viewing detailed specifications, and making secure bookings.

### 🚀 Live URL
https://b13-a8-qurbanihat.vercel.app/


### 🌟 Key Features
- **Authentication:** Secure Login and Registration using Email/Password and Google Social Login.
- **Dynamic Animal Showcase:** Browse a variety of livestock with sorting options by price.
- **Detailed Information:** View specific details like breed, weight, age, and location for each animal.
- **Booking System:** Private route for authenticated users to place bookings via a form.
- **User Profile:** Dedicated profile page to view and update user information (Name and Photo).
- **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop views.
- **Interactive UI:** Smooth animations and toast notifications for a better user experience.

### 🛠️ Tech Stack & Packages Used
- **Framework:** Next.js / React
- **Styling:** Tailwind CSS, DaisyUI
- **Authentication:** Better-Auth
- **Animations:** Animate.css
- **Notifications:**  React-Toastify
- **Icons:** React Icons
